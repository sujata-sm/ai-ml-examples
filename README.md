## Run Notebooks

### 1. Google Colab
- Download notebook and dataset
- Upload to Google Colab and run

### 2. VS Code
- Clone repository
- Install Jupyter extension
- Run notebook

### 3. Jupyter CLI
```bash
pip install jupyter
jupyter notebook
# Opens on localhost:8888
```
