# LLM Agents - TODO

Autonomous AI systems that can reason and use tools.

## What are Agents?
LLMs that can plan, execute actions, and interact with external tools to accomplish tasks.

## Techniques to Explore

| Technique | Description |
|-----------|-------------|
| **Tool Calling** | LLM invokes external functions |
| **ReAct** | Reasoning + Acting pattern |
| **Multi-step** | Chain of actions to solve complex tasks |

## Agent Flow
```
User Query → Plan → Tool Calls → Observe → Respond
```
